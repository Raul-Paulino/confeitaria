# 🍰 Confeitaria | Frontend Web Project

> Um projeto web completo de uma confeitaria artesanal, desenvolvido com foco em portfólio profissional, usabilidade e design responsivo.

---

## 🚀 Sobre o Projeto
O **Confeitaria** é um site frontend estático desenvolvido inteiramente do zero com tecnologias nativas da web. O projeto simula a experiência completa de um e-commerce e catálogo de confeitaria fina, apresentando páginas institucionais, vitrines de produtos com filtros interativos, menus suspensos (dropdowns) e um formulário dinâmico de encomendas integrado com simulação de envio.

---

## 🛠️ Tecnologias Utilizadas
- **HTML5:** Estruturação semântica e multiplataforma de páginas (`index.html`, `sobre.html`, `produtos.html`, `encomenda.html`).
- **CSS3:** Estilização avançada, Flexbox, Grid Layout, variáveis de cores personalizadas e efeitos visuais (*hover*, sombras, transições).
- **JavaScript Puro (Vanilla JS):** Interatividade de carrinho de compras, menus, busca e manipulação de formulários.
- **Google Fonts:** Tipografia moderna (*Poppins*).
- **Git & GitHub:** Versionamento de código e hospedagem via **GitHub Pages**.

---

## 📱 Páginas & Funcionalidades
1. **Home (`index.html`):** Banner principal (*Hero*), diferenciais da marca, prévia do catálogo e rodapé completo.
2. **A Confeitaria (`sobre.html`):** História da marca, blocos estatísticos de destaque e pilares de qualidade.
3. **Catálogo de Produtos (`produtos.html`):** Vitrine completa de bolos, tortas, chocolates e sobremesas com sistema de filtros por categoria.
4. **Encomendas (`encomenda.html`):** Formulário interativo para pedidos personalizados e eventos.
